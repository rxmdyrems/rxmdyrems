👋 About Me

Hey, I'm Remy — a BSIT / Computer Programming graduate from Cebu, Philippines.

My path into tech hasn't been completely traditional. I've worked as a freelancer, ESL teacher, and customer service representative, while continuing to develop my programming and web development skills.

Today, I'm focused on building useful, responsive, and maintainable web experiences.

I enjoy understanding what's happening behind the interface — from frontend interactions and APIs to databases, SQL queries, authentication, and deployment.

I also use AI-assisted development tools to speed up my workflow, but I believe AI works best when you understand the fundamentals behind what you're building.
