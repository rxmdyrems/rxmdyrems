## 👨‍💻 About Me

Hi, I'm **Remy**, a Computer Programming / BSIT graduate from Cebu, Philippines.

My journey into tech has taken a few different paths. I've worked as a **freelancer**, **ESL teacher**, and **customer service representative**, while continuing to build my skills in programming and web development.

These experiences taught me how to communicate, solve problems, work with different people, adapt quickly, and keep learning when things don't go as planned.

Today, I enjoy building **practical web applications, responsive interfaces, and database-driven systems**.

I like understanding how things work behind the screen — from the UI and APIs to SQL queries, authentication, databases, and deployment.

### ⚡ How I Work

I use modern tools, including AI-assisted development, to **work smarter and faster**.

AI helps me explore ideas, reduce repetitive work, debug, research solutions, and speed up development.

But the goal isn't to let AI build everything for me.

**I still review, understand, test, debug, and make the final decisions.**

> **Use the tools. Understand the work. Focus more time on what actually matters.**
